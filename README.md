# Hotel Reservation Analysis & Dashboard

## Project Overview
This project focuses on analyzing hotel reservation data using Microsoft Excel to understand booking patterns, customer preferences, room pricing and booking cancellations.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Slicers
- Data Cleaning

## Project Objectives
- Analyze total hotel bookings.
- Identify booking cancellation patterns.
- Compare room prices across room types.
- Understand customer booking behaviour.
- Create an interactive dashboard.

## Data Cleaning
- Removed duplicate records.
- Handled missing values.
- Standardized text values.
- Corrected data types.
- Created calculated columns.

## Key Performance Indicators
- Total Bookings
- Canceled Bookings
- Cancellation Rate
- Average Room Price
- Average Lead Time

## Business Analysis
1. Cancellation Analysis
2. Pricing Analysis

## Key Insights
- Online bookings have a higher cancellation rate.
- Room Type 6 has the highest average room price.
- Room Type 3 has the lowest average room price.
- Room Type 1 is the most frequently reserved room type.

## Outcome
Developed an interactive Excel dashboard to help hotel management understand business performance and make data-driven decisions.
